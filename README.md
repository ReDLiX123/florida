# 🌸 Салон красоты «Флорида» · Иркутск

> Премиальный веб-сайт для салона красоты «Флорида» (г. Иркутск, ул. Байкальская 124/1).
> Инновационное LED-наращивание ресниц, SMART-педикюр, ногтевой сервис, архитектура бровей, стилистика и свадебные образы.

---

## ✨ Ключевые особенности и функционал

- 🌸 **Haute-Couture дизайн и живой брендинг**: интерактивная композиция цветущей розы, плавающая адаптивная шапка и гармоничная цветовая палитра.
- ⚡ **High-Performance оптимизация (60/120 FPS)**:
  - Автоматическая пауза тяжелых анимаций в невидимой зоне через `IntersectionObserver`.
  - Аппаратное GPU-ускорение бегущих строк и орбитальных эффектов.
  - Оптимизированные медиа-ресурсы с уменьшением веса на 88%.
  - Нулевая задержка тапов (`touch-action: manipulation`) на смартфонах.
- 📱 **Mobile-First UX**: горизонтальные свайп-карусели мастеров и работ, навигация через нижнюю шторку (Mobile Sheet Drawer).
- 💅 **Каталог ритуалов красоты**: интерактивные категории с переключением табов, карточки услуг с длительностью и прайсом.
- 👩‍🎨 **Команда мастеров & Lookbook**: детальные профили мастеров с фильтрацией по направлениям и персональными галереями работ.
- 📸 **Интерактивное портфолио**: полноэкранный Lightbox-просмотр работ в высоком разрешении с возможностью записи к конкретному автору.
- ⭐ **Отзывы с независимых площадок**: социальное подтверждение с рейтингом 5.0 из 2ГИС и Яндекс Карт.
- 📅 **Онлайн-бронирование**: интерактивная форма предварительной записи, интеграция с платформой **Dikidi Online** и быстрая связь через Telegram и WhatsApp.

---

## 🛠️ Технологический стек

- **Фреймворк**: [Next.js 14 (App Router)](https://nextjs.org/)
- **Язык**: TypeScript
- **Стилизация**: [Tailwind CSS](https://tailwindcss.com/)
- **Анимации**: [Framer Motion](https://www.framer.com/motion/) + GPU CSS Keyframes
- **Иконки**: [Lucide React](https://lucide.dev/)
- **Шрифты**: Google Fonts (*Cormorant Garamond* & *Manrope* через `next/font/google`)
- **Обработка графики**: `sharp`

## 🚀 Локальный запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка проекта
npm run build

# Запуск производственного сервера
npm start
```
